# Kladit Agent

Linux-агент для мониторинга серверов в Kladit.

Текущая версия предоставляет локальный снимок загрузки CPU, памяти и времени работы сервера. Подключение к control plane пока не реализовано.

## Требования

- Linux с доступными `/proc/stat`, `/proc/meminfo` и `/proc/uptime`.
- Go 1.25 или новее для сборки. Используйте актуальный patch-релиз.

Для сбора метрик root не требуется. Внешних зависимостей нет.

## Сборка

```sh
go build -o bin/kladit-agent ./cmd/kladit-agent
```

## Использование

```sh
./bin/kladit-agent help
./bin/kladit-agent version
./bin/kladit-agent metrics --policy examples/policy.json
```

`metrics` измеряет загрузку CPU за интервал около одной секунды и выводит JSON в stdout. Ошибки направляются в stderr; код завершения — `1` при ошибке сбора и `2` при неверных аргументах.

| Поле | Значение |
| --- | --- |
| `collected_at` | Время завершения сбора, UTC |
| `cpu_usage_percent` | Средняя загрузка всех CPU, 0–100%; idle и iowait исключены |
| `memory_total_bytes` | Общий объём RAM в байтах |
| `memory_available_bytes` | Доступная память по MemAvailable, включая освобождаемый cache |
| `memory_used_bytes` | Общая память минус доступная |
| `uptime_seconds` | Время работы системы в секундах |

Метрики читаются из procfs и не учитывают лимиты контейнера cgroup. Поля снимка собираются последовательно, не атомарно. При уменьшении CPU-счётчиков сбор завершается ошибкой; повторите команду.

## Разработка

```sh
go run ./cmd/kladit-agent metrics --policy examples/policy.json
go test ./...
go vet ./...
```

Сбор метрик поддерживается только на Linux. Справка и версия доступны также на других ОС.

## Локальные разрешения

Команда `metrics` требует явного разрешения `metrics.read` в локальном JSON-файле. Путь по умолчанию: `/etc/kladit-agent/policy.json`. Для разработки можно передать `--policy PATH`.

```json
{"version": 1, "capabilities": {"metrics.read": true}}
```

Отсутствующее разрешение или `false` запрещает операцию. Отсутствующий файл, неизвестные поля и capabilities, повторяющиеся ключи и неверные значения приводят к отказу. Поддерживается только `metrics.read`.

```sh
./bin/kladit-agent policy-check --policy examples/policy.json
```

Проверка подтверждает корректность конфигурации, а не наличие разрешения на метрики. Сбор читает policy перед каждым запуском команды.

Для системной установки файл и родительские каталоги должны принадлежать администратору и быть недоступны для записи пользователю агента. Параметр `--policy` предназначен для локального запуска; будущий сервис должен использовать фиксированный путь. Проверка JSON сама по себе не защищает файл от изменения локальным пользователем или скомпрометированным процессом. Установка системного сервиса пока не реализована.

Привязка к аккаунту и сетевое подключение пока не поддерживаются.
