# Kladit Agent

Linux-агент для подключения сервера к Kladit. Разрабатываем небольшими проверяемыми шагами.

Сейчас готов только каркас CLI: справка и версия. Он не собирает метрики, не подключается к backend и не выполняет команды на сервере. Запускайте без sudo.

## Запуск для разработки

Установите актуальную исправленную версию Go 1.25 или новее с https://go.dev/dl/.

Из каталога репозитория:

```sh
go version
go run ./cmd/kladit-agent help
go run ./cmd/kladit-agent version
```

Ожидаемый вывод последней команды: `kladit-agent 0.1.0-dev`.

Разрабатывать этот шаг можно и на Windows. Целевая система самого агента — Linux.

## Сборка

```sh
go build -o bin/kladit-agent ./cmd/kladit-agent
./bin/kladit-agent version
```

На Windows:

```powershell
go build -o bin/kladit-agent.exe ./cmd/kladit-agent
.\bin\kladit-agent.exe version
```

`go run` собирает и сразу запускает программу. `go build` сохраняет готовый исполняемый файл. На целевой машине Go для запуска этого файла не нужен; файл собирается под конкретную ОС и архитектуру.

## Файлы

- `go.mod` — имя проекта и минимальная версия Go; примерно роль метаданных `package.json`. Внешних зависимостей пока нет.
- `cmd/kladit-agent/main.go` — точка входа. Go вызывает функцию `main()` при запуске.
- `docs/PLAN.md` — сделанное, следующий шаг и ограничения безопасности.
- `.gitignore` — исключает результаты сборки и локальные env-файлы. Секреты всё равно нельзя коммитить.

## Проверка

```sh
gofmt -w cmd/kladit-agent/main.go
go vet ./...
go test ./...
```

Автоматических тестов пока нет; `go test` проверяет компиляцию пакетов. CLI проверяется запуском справки, версии и неизвестной команды (код выхода 2 у собранного бинарника).
