# Kladit Agent

Linux-агент для мониторинга серверов в Kladit.

Текущая версия предоставляет локальный снимок загрузки CPU, памяти и времени работы сервера. Подключение к control plane пока не реализовано.

## Требования

- Linux с доступными `/proc/stat`, `/proc/meminfo` и `/proc/uptime`.
- Go 1.25 или новее для сборки. Используйте актуальный patch-релиз.

Для сбора метрик root не требуется. Внешних зависимостей нет.

## Сборка

```sh
go build -o bin/kladit-agent ./cmd/kladit-agent
```

## Использование

```sh
./bin/kladit-agent help
./bin/kladit-agent version
./bin/kladit-agent metrics
```

`metrics` измеряет загрузку CPU за интервал около одной секунды и выводит JSON в stdout. Ошибки направляются в stderr; код завершения — `1` при ошибке сбора и `2` при неверных аргументах.

| Поле | Значение |
| --- | --- |
| `collected_at` | Время завершения сбора, UTC |
| `cpu_usage_percent` | Средняя загрузка всех CPU, 0–100%; idle и iowait исключены |
| `memory_total_bytes` | Общий объём RAM в байтах |
| `memory_available_bytes` | Доступная память по MemAvailable, включая освобождаемый cache |
| `memory_used_bytes` | Общая память минус доступная |
| `uptime_seconds` | Время работы системы в секундах |

Метрики читаются из procfs и не учитывают лимиты контейнера cgroup. Поля снимка собираются последовательно, не атомарно. При уменьшении CPU-счётчиков сбор завершается ошибкой; повторите команду.

## Разработка

```sh
go run ./cmd/kladit-agent metrics
go test ./...
go vet ./...
```

Сбор метрик поддерживается только на Linux. Справка и версия доступны также на других ОС.
